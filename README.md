# Media Command Center

A personal tracker for manhwa (and soon movies, shows, and more), built with React, Vite, Tailwind, and Firebase.

See `AUDIT.md` for the project audit and `BUILD_DIRECTIVE.md` for the phased build plan.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. (Phase 1+) Copy `.env.example` to `.env.local` and set `VITE_TMDB_API_KEY` for movie/TV search.
3. Run the app:
   `npm run dev`
